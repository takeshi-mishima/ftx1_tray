# FTX-1 トレイ Ver.2.0

八重洲無線 FTX-1 を、Windows のタスクトレイのアイコンクリックだけで操作する常駐ツールです。
Hamlib の rigctld 経由で無線機を制御するため、WSJT-X などの CAT ソフトと同時に使えます。
（WSJT-X なども rigctld で制御するように設定しておく必要があります。）

## 機能

| 機能 | 動作                                                |
| ---- | --------------------------------------------------- |
| SWAP | 操作バンドを MAIN ⇔ SUB で入れ替える                |
| VFO  | 操作バンドがメモリーなどのときに VFO モードに戻す   |
| M145 | MAIN を 145.00MHz FM にし、操作バンドを MAIN にする |
| M433 | MAIN を 433.00MHz FM にし、操作バンドを MAIN にする |
| S145 | SUB を 145.00MHz FM にし、操作バンドを SUB にする   |
| S433 | SUB を 433.00MHz FM にし、操作バンドを SUB にする   |
| FN1  | FUNC ツマミを回したときの機能を、設定した機能にする |
| FN2  | 同上（FN1 とは別の機能を設定できます）              |

8つの機能を、それぞれ好きなクリック操作に割り当てられます（「設定」参照）。
VFO、FN1、FN2 は初期状態では割り当てていません。

FN1 / FN2 は、本体で [FUNC] ツマミを押して機能を選ぶ操作の代わりになります。
たとえば FN1 を D-LEVEL にしておけば、クリックひとつで FUNC ツマミが
スコープのレベル調整になります。

## 動作環境

- Windows 10 / 11
- FTX-1（CAT 動作には MAIN ファームウェア Ver.1.08 以上が必要です）
- Hamlib の rigctld が FTX-1 に接続して起動していること
- Hamlib は 4.7.3 以上を推奨します（2026年9月時点では、開発版の 4.7.3~rc を
  https://hamlib.sourceforge.net/snapshots-4.7/ から入手できます）。
  4.7.0 では（4.7.1 / 4.7.2 は未確認）、操作バンドが W-FM（FM 放送のメモリーなど）のときに rigctld がモードを読み取れずエラーになり、
  WSJT-X などが接続していると、rigctld が接続を開き直すことを繰り返します。
  その間は FTX-1 トレイの操作が数秒待たされたり、タイムアウトしたりします。

rigctld の起動例（COM ポート、TCP ポートは環境に合わせてください）:

```
rigctld -m 1051 -r COM5 -s 38400 -t 4534
```

FTX-1 のモデル番号は 1051 です。
COM ポートは Enhanced COM Port（CAT-1）を指定します。

## インストール

1. 任意のフォルダに `ftx1_tray.exe` と `ftx1_tools.ini` を置きます
2. `ftx1_tools.ini` の `[rigctld]` セクションで、rigctld の接続先（host / port）を設定します
3. `ftx1_tray.exe` を起動すると、タスクトレイにアイコンが表示されます

Windows 起動時に自動で起動したい場合は、`Win + R` で `shell:startup` を開き、
`ftx1_tray.exe` のショートカットを置いてください。

初回起動時に「Windows によって PC が保護されました」と表示された場合は、
「詳細情報」→「実行」で起動できます（署名のない exe のため表示されます）。

## 使い方

### 初期の割り当て

| 操作                     | 機能                         |
| ------------------------ | ---------------------------- |
| 左クリック               | S145                         |
| 左ダブルクリック         | S433                         |
| 右クリック               | M145                         |
| 右ダブルクリック         | M433                         |
| ホイールボタンのクリック | SWAP                         |
| （なし）                 | VFO / FN1 / FN2              |
| Shift + 右クリック       | メニュー（設定 / 終了）※固定 |

### アイコン

左半分が SUB（S）、右半分が MAIN（M）です。操作バンドになっている側が色付き
（SUB = 緑、MAIN = 青）で、もう一方はグレーになります。
無線機が接続されていない、rigctld に接続できないなど、
状態がわからないときは両方ともグレーです。

アイコンの状態は、起動時、およびこのツールで操作したときに更新します。
無線機本体で操作バンドを切り替えた場合は、次にこのツールを操作したときに表示を更新します。

### ツールチップ

アイコンにマウスを重ねると、操作バンド、機能の割り当て、最後に実行した操作を表示します。

```
FTX-1 操作バンド: MAIN
SWAP=C-SGL
M145=R-SGL M433=R-DBL
S145=L-SGL S433=L-DBL
最終: MAIN 433.000 FM
```

FN1 / FN2 は、割り当てた FUNC ツマミの機能名で表示します（例: `D-LEVEL=L-CTL RF POWER=R-CTL`）。
ツールチップは Windows の制限で127文字までのため、多くの機能を割り当てると
最後の行（最終）が途中で切れることがあります。

### エラー表示

rigctld に接続できない場合や、rigctld がエラーを返した場合は、
Windows の通知（バルーン）でエラー内容を表示します。

## 設定

Shift + 右クリック →「設定...」で設定画面を開きます。
各機能について、BUTTON と OPE をプルダウンで選びます。

| BUTTON | 意味           |
| ------ | -------------- |
| L      | 左ボタン       |
| C      | ホイールボタン |
| R      | 右ボタン       |
| -      | 割り当てなし   |

| OPE | 意味             |
| --- | ---------------- |
| SGL | 1回クリック      |
| DBL | ダブルクリック   |
| TPL | トリプルクリック |
| CTL | Ctrl + クリック  |

- 同じ操作を2つの機能に割り当てることはできません（OK を押したときにエラーになります）
- C（ホイールボタン）は SGL と CTL だけ使えます。Windows 11 のタスクトレイが、
  ホイールボタンのダブルクリックの2回目を通知しないため、DBL / TPL は判定できません
  （選ぶと OK を押したときにエラーになります）
- OK を押すと `ftx1_tools.ini` に保存し、すぐに反映します
- `ftx1_tools.ini` をメモ帳で直接編集した場合は、ツールを再起動すると反映します。
  設定画面で OK を押すと ini 全体を書き直すため、手で書き足したコメントは消えます

### FN1 / FN2 の機能（KNOB）

FN1 と FN2 の行には KNOB のプルダウンがあり、FUNC ツマミに設定する機能を選びます。
初期値は FN1 = D-LEVEL、FN2 = RF POWER です。

| KNOB                                             | 内容                   |
| ------------------------------------------------ | ---------------------- |
| D-LEVEL / D-PEAK / D-COLOR / D-CONTRAST / DIMMER | ディスプレイ・スコープ |
| MIC GAIN / PROC LEVEL / AMC LEVEL                | マイク・送信音声       |
| VOX GAIN / VOX DELAY                             | VOX                    |
| RF POWER                                         | 送信出力               |
| MONI LEVEL / CW SPEED / CW PITCH / BK-DELAY      | モニター・CW           |

CAT の SF コマンドで設定できる機能だけを選べます。ATT や NB など、
ON / OFF を切り替える項目は FUNC ツマミの機能として設定できません。
KNOB の設定は `ftx1_tools.ini` の `[funcknob]` セクションに保存します。

### クリックの反応について

ダブルクリック（DBL）やトリプルクリック（TPL）を割り当てたボタンは、
「次のクリックが来るか」を待つため、1回クリックの動作が Windows のダブルクリック時間
（標準で約0.5秒）だけ遅れて実行されます。DBL も TPL も割り当てていないボタンは、すぐに実行します。

## ビルド方法

ソースから exe を作る場合の手順です。exe を使うだけなら不要です。

1. Python 3 をインストールします（外部ライブラリは不要です）
2. PyInstaller をインストールします

   ```
   py -m pip install pyinstaller
   ```

3. `build.bat` を実行すると、`dist\ftx1_tray.exe` ができます

## その他

タスクマネージャに `ftx1_tray.exe` が2つ表示されますが正常です。

`ftx1_tray.exe` のサイズは約12MBと大きめですが、正常です。
Python 本体と、設定画面で使う Tcl/Tk（tkinter）を exe の中に同梱しているためです。
